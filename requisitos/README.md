# Repositorio de Requerimientos - Sistema de Registro de Cámaras de Seguridad

Este directorio contiene la documentación, trazabilidad, control de cambios y pruebas de los requerimientos del proyecto.

## Estructura
- `/funcionales`: Requerimientos funcionales (`RF-01` a `RF-05`).
- `/no_funcionales`: Requerimientos no funcionales (`RNF-01` a `RNF-03`).
- `/modelos`: Diagramas, bocetos y prototipos de interfaz.
- `/cambios`: Registro de solicitudes de cambio (`CR-XX`).
- `/trazabilidad`: Matriz de trazabilidad en formato CSV.
- `/pruebas`: Casos de prueba y criterios de aceptación.
